# 个人记账 Agent 路线图

## 当前状态

截至 2026-07-11，项目已经完成第一轮账本可靠性 P0：

- 可切换的 OpenAI-compatible Provider 负责自然语言账单解析和安全工具路由。
- SQLite 负责账本、预算、操作审计、Agent 调用日志和轻量对话上下文。
- 一句话可生成一条或多条可编辑草稿，确认后通过 SQLite 事务整批写入。
- 支持账单搜索、编辑、软删除、撤销、CSV 导入和导出。
- 支持确定性月度汇总、预算进度、规划建议和月报。
- 本地 Web 已提供对话、账单、账户与对账、预算、订阅、待还、日志和账本设置八个可用视图。
- 支付、投资、贷款和报税始终不执行，只能转为规划或提醒；账户转账只记录本地账本，必须确认，不调用外部支付接口。

## 已完成

### LLM Agent

- 支持任意 OpenAI-compatible 服务与火山方舟，并可在 Web 中切换 Provider 和模型。
- 单轮与持续对话入口。
- `clarify`、`record`、`summary`、`plan`、`search`、`where`、`report` 七类安全动作。
- 金额、日期或拆分方式不明确时使用 `clarify` 追问，不生成猜测草稿。
- 对话模型从 SQLite 实时分类表中选择分类，并返回置信度和理由。
- 用户确认分类后形成本地商户记忆，后续优先于模型猜测。
- 无合适分类时 Agent 可提出新分类，用户批准后才创建并应用。
- SQLite 会话消息、偏好和最近状态。
- 页面刷新可恢复聊天历史、响应中请求和待确认草稿。
- 自然语言入口不使用正则规则降级，模型失败时明确报错。

### 本地账本

- SQLite 交易和分类预算。
- 自然语言账单指纹去重；命中后默认阻止写入，用户二次确认后才可保留真实重复消费。
- 分类与支付方式标准表、别名归一、常用标记、改名和合并；历史账单与分类预算同步迁移。
- 编辑、软删除、撤销和审计日志。
- 支付宝/微信 CSV 预览导入、来源保留和指纹去重。
- 导入账单不发给 LLM，分类统一标记为“待分类”。
- 搜索明细、花费去向聚合、CSV 导出。
- 完整 SQLite 备份、下载、完整性校验和确认恢复。
- 待分类账单支持当前 LLM 批量分类，高置信度自动更新、低置信度保留复核。
- 订阅管理：维护周期、下次扣款日、分类和支付方式，区分今日、逾期、未来和停用状态；明确确认扣款后才写入真实支出，也可跳过一期而不写账。
- 待还管理：覆盖信用卡、花呗、月付、分期和个人欠款；每个月独立记录原始应还、本月已还、本月未还、可选还款日和最低还款，并可直接切换所有已有账单月份。个人欠款没有约定日期时可留空，不会被误判为逾期；登记还款减少未还，但不会重复写入消费支出。
- 真实账户与对账：微信、支付宝、银行卡、现金及自定义账户有独立余额；本金自动等于账户余额之和。收入、支出、订阅扣款和已指定账户的实际还款会影响对应账户；账户转账不计入收支。每次对账保存实际余额与差异，旧版本金迁移为待分配余额。

### Web UI

- 对话记账、草稿编辑和确认写入。
- 多草稿逐条编辑、移除、批量确认和整批撤销。
- 账单搜索、收支筛选、编辑、删除和撤销。
- 分类预算新增、进度展示和删除。
- 月度收支、分类分布和最近交易。
- 操作记录与 Agent 调用日志，支持类型、状态筛选和手动刷新。
- 批量写入有独立批次日志；撤销前显示整批笔数，撤销后显示批次号。
- 分类、支付方式和备份管理页。
- 订阅和待还视图，包含新增、编辑、停用、订阅扣款确认与还款登记。
- localhost 健康检查、禁用旧静态资源缓存、可靠启停与重启脚本。

## 安全边界

- API key 只存放于被 Git 忽略的 `.env`。
- 账本明细默认不发送给模型；模型只看到当前输入和必要对话上下文。
- SQL 负责所有金额统计，LLM 不自行计算账本数字。
- 批量导入、写入和删除都保留确认或撤销能力。
- Web 默认只绑定 `127.0.0.1`，未实现鉴权前不允许暴露到局域网或公网。
- 不保存银行、支付平台或券商登录凭证。
- Agent 日志不复制完整输入、系统提示词或 API Key，只保存调用元数据和错误摘要。

## 下一阶段

### 已启动：Agent 可靠性与分析能力

- 原生工具定义与字段说明统一维护在 Pydantic Tool Schema；系统 Prompt 只保留通用安全规则。
- `evals/redaction_cases.json` 与默认 pytest 回归覆盖敏感信息脱敏、搜索结果最小披露和工具能力来源。
- 对话请求提供 SSE 进度状态，显示上下文准备、模型调用、本地工具执行和结果保存。
- 对话 Agent 可读取订阅与月度待还清单，回答本月预计扣款、原始应还和本月未还；创建、扣款和还款仍须在本地界面明确确认。
- Agent 可识别建立订阅、已有订阅已扣款、待还账单更新和已还款语句，并生成可编辑草稿；确认前不写入 SQLite。
- 支持将 PNG/JPEG/WebP 账单截图交给图片模型生成多笔待确认草稿；图片不写入日志或 SQLite Checkpoint。
- 支持任意两个日期区间比较，以及订阅/房租等周期性支出候选识别。

### P1：日常可用性

1. Web 增加 CSV 上传和导入草稿逐条确认。
2. 增加月报文件导出。
3. 为中转站增加重试和更细的可读错误分类。

### P2：隐私与部署

1. 评估 SQLCipher 或操作系统全盘加密，不自行设计加密算法。
2. 将 API key 迁移到操作系统密钥链。
3. 配置 systemd 用户服务，实现登录后自动启动。
4. 增加本机访问口令后，再考虑局域网访问。

### P3：消息入口

优先接飞书机器人，只把它作为消息入口，核心账本仍由本地 Web 和 SQLite 管理。微信接入需要更复杂的账号资质和公网回调，放在飞书验证后。任何消息入口都不能获得付款或资金移动权限。
